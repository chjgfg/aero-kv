# User Guide
This document includes the setup of the local development environment for Aero-KV, full deployment procedures, and instructions for using the one-click startup scripts.

## 1. Prerequisites
- Rust 1.70+
- Anchor 0.29+
- Node.js 18+
- Solana CLI
- Docker (Optional)

## 2. One-Click Deployment (Recommended)
All scripts are located in the `sh/` directory at the project root. Execute them in the following order:

```bash
cd sh
# 1. Create test wallet
./wallet_start.sh
# 2. Start local validator and deploy contracts
./contract_start.sh 
# 3. Start backend cluster
./backend_start.sh 
# 4. Start proxy server
./proxy_start.sh 
# 5. Start frontend
./frontend_start.sh 
```

## 3. Stop Services
```bash
./frontend_stop.sh 
./proxy_stop.sh 
./backend_stop.sh 
./contract_stop.sh 
./wallet_stop.sh
```

## 4. Manual Deployment Steps

### Contract Deployment
```bash
solana-test-validator -r
cd contract
anchor build
anchor deploy
```

### Backend Raft Cluster Startup
```bash
cd backend
cargo run -- 1 8001
cargo run -- 2 8002
cargo run -- 3 8003
```

### Initialize Raft Cluster
```bash
curl -X POST http://127.0.0.1:8001/raft/init -H "Content-Type: application/json" -d '{
    "1": { "addr": "127.0.0.1:8001" },
    "2": { "addr": "127.0.0.1:8002" },
    "3": { "addr": "127.0.0.1:8003" }
}'
```

### Proxy Startup
```bash
cd proxy
cargo run --release
```

### Frontend Startup
```bash
cd frontend
npm install
npm run dev
```
