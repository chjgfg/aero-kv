# Contract Documentation
This document describes the PDA account structure, Page instructions, event parsing rules, and permission control details of the Aero-KV contract.

## I. Contract Features
- On-chain key-value data storage
- Event broadcasting (KVEvent)
- Permission verification
- System fee management
- Total data count tracking

## II. PDA Account Structure
- Auth PDA: Permission control account
- Fee PDA: Transaction fee configuration account
- Counter PDA: Total data statistics account
- KVStore PDA: Key-value data storage account

## III. Core Instructions
- initialize: Initialize the contract
- upsert/delete/scan/page/get: Set or query key-value data
- fee: Configure transaction fees
- pause: Enable or disable the system

## IV. Event Parsing
KVEvent contains:
- key
- value

## V. Permission Control
- Only administrators can modify system configurations
- Regular users can only read and write business data
- System configurations prefixed with `sys_*` are not exposed externally
