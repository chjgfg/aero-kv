# FAQ
This document summarizes common issues and solutions for project deployment, operation, data anomalies, and node failures.

## 1. Script permission denied
Grant execution permission first:
```bash
chmod +x *.sh
```

## 2. Contract deployment failed
- Check if the local test validator is running properly
- Ensure the test wallet has enough SOL
- Re-run: ./contract_start.sh

## 3. Backend Raft node failed to start
- Check if ports 8001/8002/8003 are occupied
- Ensure Rust version >= 1.70
- Stop old nodes and restart

## 4. /raft/init API error (incorrect URL / inaccessible)
- Ensure backend node 1 (8001) is running
- Ensure startup command is correct: cargo run -- 1 8001
- Wait 3 seconds before running the curl init command
- Check that the request method is POST

## 5. Frontend cannot access / API request failed
- Ensure the proxy is running
- Check service status at http://localhost:80/health
- Ensure the backend cluster is running normally

## 6. Empty query result / data inconsistency
- Check if contract events are parsed normally
- Restart backend nodes to sync logs
- Ensure data has been successfully written on-chain
- sys_* system configurations are filtered by default and not displayed in the business list

## 7. Port occupied
Find and kill the process using the port:
```bash
lsof -i:port
kill -9 PID
```

## 8. Raft cluster out of sync
- Ensure all three nodes are running
- Re-run the cluster initialization command
- Check node network connectivity and port accessibility

## 9. Frontend page displays abnormally
- Ensure Node.js version >= 18
- Re-run npm install
- Restart the frontend service
