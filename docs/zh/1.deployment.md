# 使用指南
本文档包含 Aero-KV 本地开发环境搭建、全流程部署步骤、以及一键启动脚本使用说明。

## 一、环境依赖
- Rust 1.70+
- Anchor 0.29+
- Node.js 18+
- Solana CLI
- Docker（可选）

## 二、一键脚本部署（推荐）
所有脚本位于项目根目录 `sh/` 下，按顺序执行：

```bash
cd sh
# 1. 创建测试钱包
./wallet_start.sh
# 2. 启动本地合约环境并部署合约
./contract_start.sh 
# 3. 启动后端集群
./backend_start.sh 
# 4. 启动代理端
./proxy_start.sh 
# 5. 启动前端
./frontend_start.sh 
```

## 三、停止服务
```bash
./frontend_stop.sh 
./proxy_stop.sh 
./backend_stop.sh 
./contract_stop.sh 
./wallet_stop.sh
```

## 四、手动部署步骤

### 合约部署
```bash
solana-test-validator -r
cd contract
anchor build
anchor deploy
```

### 后端 Raft 集群启动
```bash
cd backend
cargo run -- 1 8001
cargo run -- 2 8002
cargo run -- 3 8003
```

### 初始化 Raft 集群
```bash
curl -X POST http://127.0.0.1:8001/raft/init -H "Content-Type: application/json" -d '{
    "1": { "addr": "127.0.0.1:8001" },
    "2": { "addr": "127.0.0.1:8002" },
    "3": { "addr": "127.0.0.1:8003" }
}'
```

### 代理启动
```bash
cd proxy
cargo run --release
```

### 前端启动
```bash
cd frontend
npm install
npm run dev
```
