# 合约说明文档
本文档说明 Aero-KV 合约的 PDA 账户结构、Page 指令、事件解析规则与权限控制细节。

## 一、合约功能
- 链上键值数据存储
- 事件广播（KVEvent）
- 权限校验
- 系统费用管理
- 数据总量计数

## 二、PDA 账户结构
- Auth PDA：权限控制账户
- Fee PDA：手续费配置账户
- Counter PDA：数据总量统计账户
- KVStore PDA：键值数据存储账户

## 三、核心指令
- init*：初始化合约
- upsert/delete/scan/page/get：设置/查看键值
- fee：手续费
- pause：系统开关

## 四、事件解析
KVEvent 包含：
- key
- value

## 五、权限控制
- 只有管理员可修改系统配置
- 普通用户只能读写业务数据
- sys_* 前缀系统配置不对外暴露
