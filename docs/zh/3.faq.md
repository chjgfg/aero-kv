# FAQ 常见问题

本文档汇总项目部署、运行、数据异常、节点故障等高频问题与解决方案。

## 1. 执行脚本提示权限不足
请先赋予脚本执行权限：
```bash
chmod +x *.sh
```

## 2. 合约部署失败
- 检查本地测试节点是否正常启动
- 确认测试钱包有足够 SOL
- 重新执行：./contract_start.sh

## 3. 后端 Raft 节点启动失败
- 检查端口 8001/8002/8003 是否被占用
- 确认 Rust 环境版本 >= 1.70
- 关闭旧节点后重新启动

## 4. /raft/init 接口报错（URL 不正确 / 无法访问）
- 确认后端节点 1（8001）已正常启动
- 确认节点启动命令格式正确：cargo run -- 1 8001
- 等待 3 秒再执行 curl 初始化
- 检查请求方式是否为 POST

## 5. 前端无法访问 / 接口请求失败
- 确认 proxy 已启动
- 访问 http://localhost:80/health 检查服务状态
- 确认后端集群正常运行

## 6. 数据查询为空 / 数据不一致
- 检查合约事件是否正常解析
- 重启后端节点同步日志
- 确认数据已成功上链
- sys_* 系统配置默认过滤，不显示在业务列表

## 7. 端口被占用
执行以下命令找到占用进程并关闭：
```bash
lsof -i:端口号
kill -9 进程ID
```

## 8. Raft 集群不同步
- 确认三个节点都已启动
- 重新执行集群初始化命令
- 检查节点网络与端口是否互通

## 9. 前端页面显示异常
- 确认 Node.js 版本 >= 18
- 重新执行 npm install
- 重启前端服务
